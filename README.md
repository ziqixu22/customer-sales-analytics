# Customer Sales Analytics Dashboard

Interactive Tableau project for exploring customer purchasing behavior and sales performance across products, geography, payment methods, and customer segments.

## Project Overview

This dashboard turns transaction-level sales data into a business-oriented view of customer behavior. The analysis is designed to help answer questions such as which customer segments contribute the most revenue, how purchasing patterns vary across regions and categories, and how payment and discount behavior relate to sales performance.

## Business Questions

- Which customer segments generate the most sales?
- How do sales vary by product category and geography?
- What patterns appear across payment methods and discount levels?
- Which customers or regions contribute disproportionately to revenue?

## Tools

- Tableau
- Data visualization
- Customer analytics
- Sales KPI analysis
- Geographic analysis

## Data Notes

The source dataset is publicly available and contains customer and transaction-level fields used for analysis. Some raw fields in the source schema are not analytically necessary; the portfolio focuses on aggregated business insights rather than personally identifying fields.

## Portfolio Takeaway

This project demonstrates the ability to translate granular transactional data into an interactive business intelligence dashboard and communicate customer and sales patterns visually.
